# Welcome

### IT • Networking • System Administration

I'm building hands-on experience in networking, system administration,
and virtualization through practical projects and home labs. I document
my configurations, troubleshooting, and lessons learned along the way.

- **Networking:** Cisco Packet Tracer, Cisco IOS, TCP/IP, subnetting, VLANs, DHCP, and ACLs
- **System Administration:** Windows Server, Active Directory, Group Policy, DNS, PowerShell, and Linux
- **Virtualization & Storage:** Proxmox VE, Windows and Linux VMs, TrueNAS, and SMB shares
- **Access Management:** Security groups, role-based access control, and NTFS permissions
- **Version Control & Documentation:** Git, GitHub, incident reports, and knowledge base articles

## 📂 Featured Projects

### 🌐 [Cisco Network Game Development Studio](https://github.com/SoulgrimDev/Cisco-Project)

Designed a network for a fictional four-floor indie game development
studio using Cisco Packet Tracer.

- Segmented business, production, QA, and voice traffic using four VLANs and /26 subnets.
- Planned inter-VLAN routing with router subinterfaces and 802.1Q trunks.
- Designed extended ACLs to restrict access to protected networks.
- Configured DHCP, RIP, and IP telephony, and disabled unused switch ports.

### 🏢 [Active Directory Lab](https://github.com/SoulgrimDev/AD-Project)

Built a Windows domain environment to practice centralized user,
computer, and resource management across five simulated departments.

- Deployed Windows Server with Active Directory Domain Services, DNS, and file services.
- Joined a Windows 11 workstation to the domain.
- Organized users and security groups within an OU hierarchy.
- Implemented role-based access using AGDLP group nesting and NTFS permissions.
- Configured SMB shares, Access-Based Enumeration, and automated drive mapping.
- Applied Group Policy for security, auditing, and department-specific settings.
- Validated permissions and policy application using PowerShell and gpresult.

### 🖥️ [Proxmox Home Lab](https://github.com/SoulgrimDev/Proxmox-Homelab)

Manage a virtualized home lab to develop practical administration,
storage, and troubleshooting skills.

- Run Windows and Linux virtual machines in Proxmox VE.
- Manage TrueNAS mirrored storage, SMB shares, and access permissions.
- Troubleshoot issues including Debian DNS failures and faulty HBA cabling.
- Back up and restore VMs, including moving VM disks off the boot pool to reduce I/O contention.
- Document incidents, root causes, changes, and solutions on GitHub using an ITIL-style workflow.
